# Go CI/CD Pipeline Project

![Build Status](https://github.com/holuwateemeeleyin/go-cicd-pipeline/actions/workflows/ci.yml/badge.svg)

A containerized Go web server with a fully automated CI/CD pipeline.

## Features
* **Language:** Golang 1.22
* **Containerization:** Multi-stage Docker builds for minimal image size.
* **CI/CD:** GitHub Actions for automated testing and build verification.
